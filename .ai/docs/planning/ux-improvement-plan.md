## Resumen

Este plan prioriza mejoras UX que se pueden implementar en sesiones cortas. No hay deadlines rígidos — avanzá a tu ritmo.

---

## FASE 1: Quick Wins (2-3 horas)

### 1.1 Portadas con título
Mostrar el nombre del libro en el placeholder de portada.

**Cambio:**
```
ANTES: [Cuadrado de color] + ícono libro
DESPUÉS: [Cuadrado de color] + título del libro (2-3 líneas) + ícono chico abajo
```

**Implementación:**
- Usar fuente serif para el título (ej: `font-family: Georgia, serif`)
- `line-clamp-3` para truncar
- Ícono del libro más pequeño, posicionado abajo-centro

---

### 1.2 Estados conversacionales
Cambiar textos fríos por mensajes humanos.

| Antes | Después |
|-------|---------|
| "Unknown Author" | "Detecting..." |
| "Reading progress 0%" | Ocultar hasta que haya datos |
| "Processing" | "Preparing..." |

---

### 1.3 Jerarquía de botones
En Book Overview, hacer obvia la acción principal.

```
[Continue Reading]      ← solid, primary
[Test your knowledge]   ← outline, secondary
```

---

### 1.4 Acciones en menú
Mover Settings y Delete a un menú de 3 puntos (visible en hover).

```
[⋮]
  ├─ Edit Details
  ├─ Export
  └─ Delete (rojo)
```

---

## FASE 2: Flujo mejorado (1 día)

### 2.1 Contexto de lectura
Mostrar dónde quedó el usuario.

```
[Continue Reading]
↳ Chapter 3: Storage and Retrieval
↳ Left off 2 hours ago
```

---

### 2.2 Progreso unificado
Reemplazar las 3 barras de progreso por un donut chart.

```
    ╭──────╮
    │  34% │   ← promedio de lectura + notas + tests
    ╰──────╯
    
📖 3/6 read
📝 2/6 notes
✅ 1/6 tested
```

---

### 2.3 Capítulos agrupados
Dividir la lista por estado en lugar de mostrar todo junto.

```
✅ Completed (3)
  1. Introduction
  2. Reliable, Scalable...
  3. Storage and Retrieval

⏳ In Progress (1)
  4. Encoding and Evolution — 45%

⭕ Not Started (2)
  5. Replication
  6. Partitioning
```

---

### 2.4 Card "Insights" mejorada
Cambiar título largo y mostrar origen del contenido.

```
💡 Key Insights                          [Edit]
─────────────────────────────────────────────
"The core insight is that data systems..."

— Generated by AI
```

---

## FASE 3: Polish visual (1-2 días)

### 3.1 Portadas por categoría
Detectar tipo de libro y aplicar color/patrón diferente.

| Tipo | Color sugerido |
|------|----------------|
| Tech | Azul-morado |
| Business | Naranja-ámbar |
| Science | Verde-azulado |
| Otro | Gris-azulado |

Podés inferir por keywords en el título o dejar aleatorio por ahora.

---

### 3.2 Empty state con personalidad
Cuando no hay libros subidos:

```
      📚
   
Your library is empty

Upload your first PDF to start
building your knowledge base.

[Upload a Book]
```

---

### 3.3 Micro-animaciones
- Transición suave cuando un libro pasa de "Processing" a "Ready"
- Hover sutil en tarjetas (`transform: translateY(-2px)`)
- Checkmark animado al completar un capítulo

---

## FASE 4: Nice to have (cuando te pinte)

### 4.1 Reading streak
Heatmap estilo GitHub de días de lectura.

### 4.2 Focus mode
Toggle para lectura sin distracciones + timer Pomodoro.

### 4.3 Onboarding contextual
Tooltips que aparezcan una sola vez:
- Primera vez subiendo: "Estamos procesando tu libro..."
- Primera vez leyendo: "Seleccioná texto para destacar"

---

## Notas de implementación

- Usá Framer Motion que ya está en el proyecto
- Para el donut chart: `recharts` es liviano o podés hacerlo con SVG puro
- Mantené los cambios atómicos — un commit por tarea
- No te preocupes por mobile-first, es desktop-first por ahora
